This project was performed using React + TypeScript + Vite.

# Run project

It is neseccary to perform the following command `npm run dev` in order to start the project in the development mode.

# Project target

This project was carried out for educational purposes. It was necessary to implement SPA with a few routes using React Router v6. It includes home page with categories, page with list of the elements in all these categories and detailed page about the element. In the project information about the episodes, characters and locations in the world of Rick and Morty was provided as mock data.
